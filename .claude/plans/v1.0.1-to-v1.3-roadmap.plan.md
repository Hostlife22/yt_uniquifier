# Plan: yt-uniquifier v1.0.1 → v1.3 — best-in-class roadmap (2026-06-14)

**Source**: Conversational audit (deep code audit + competitor research + architecture review, all verified inline). No PRD; this file is the spec of record.
**Selected scope**: 33 concrete initiatives across 7 priority groups (P0–P7), staged across 4 releases (v1.0.1 hotfix → v1.3).
**Complexity**: Large (multi-quarter program). Each release is independently shippable.

---

## Summary

v1.0.0 is shipped, contract-frozen, 942 tests green. The gaps to "dominate the legitimate-uniquifier segment" cluster in three areas: (1) two real correctness bugs around resume integrity (keyframe-cache atomicity + audio-chain invariant); (2) supply-chain / distribution trust (signing, SBOM, attestation) — every non-Linux user today hits a Gatekeeper/SmartScreen warning, and there's no SBOM/cosign/CodeQL/Dependabot. Distribution stays via GitHub Releases only; third-party package registries (Homebrew/winget/Flathub) are intentionally out of scope. (3) competitive feature gaps (AV1 output, neural fingerprint estimator, plugin sandboxing, watermark/DRM guardrails). The plan addresses all three without breaking the v1.0 SemVer contract.

Verification of the audit pass that produced this plan:
- 4 of 10 "CRITICAL/HIGH" findings were **false positives** (exception-swallowing in orchestrator is the documented design; path-traversal in web/app.py is correctly blocked by `.resolve().relative_to()`; `_flush` lock is held by all public mutators; `yaml.safe_load` is used everywhere).
- 2 real defects confirmed: keyframe-cache lacks atomic fsync+rename (unlike `encoder.py`); audio-chain wrap path has no `__IN__` placeholder guard (video path does).
- Architecture/supply-chain gaps confirmed via `ls .github/workflows/` (no dependabot/codeql/sbom).

## v1.0.1 / Task 3: per-segment checksum on resume

- **Files**:
  - `src/yt_uniquifier/core/models.py` — extend `Segment` with `sha256: str | None = None`.
  - `src/yt_uniquifier/core/checkpoint.py` — `mark(idx, "done", *, sha256: str | None = None)`; persist; on `load()` recompute hash for each `done` segment if `out_path.exists()`, and demote to `"pending"` on mismatch or 0-byte file.
  - `src/yt_uniquifier/core/orchestrator.py` — after segment success, compute sha256 (streamed, 1 MiB chunks) and pass to `store.mark`.
- **Mirror**: `tests/contracts/` snapshot pattern — bumping `Segment` is an intentional decision; document in `docs/api-contracts.md` as additive/stable.
- **Test**: `tests/integration/test_resume_truncated.py` — encode 5 segments → truncate seg_0003.mkv to 0 bytes → resume → assert seg_0003 re-encoded (status went `done` → `pending` → `done`).
- **Validate**: `pytest tests/integration -k resume_truncated -q -m integration`
- **Plan-hash impact**: none. `Segment.sha256` is post-hoc, not hashed into `Plan`.
- **Risk**: Medium. Streaming hash is fast (~500 MB/s SHA256 on modern CPUs) but adds wall-clock to short segments. Mitigate: hash in background thread on the `on_segment_done` callback.

**Decision (2026-06-14)**: full Apple notarization requires $99/year Apple Developer Program — **declined to keep zero-budget**. - **File**: `installers/macos/codesign-adhoc.sh` (CREATE), `.github/workflows/release.yml` (UPDATE)
- **Action**:
  1. After PyInstaller build: `codesign --deep --force --sign - yt-uniq-gui.app` (ad-hoc signature, `-` means anonymous). Stabilises the bundle across macOS updates and avoids "is damaged" errors that hit *unsigned* bundles after a few OS versions.
  2. Zip with `ditto -c -k --keepParent yt-uniq-gui.app yt-uniq-gui-macOS.zip`.
  3. Upload to GH release.
- **Docs**: `docs/install.md` § macOS — explicit bypass: download → right-click .app → Open → confirm → ever after launches normally. Same UX as HandBrake pre-signing and Audacity-style OSS apps.
- **Validate**: download zip on a clean Mac, follow bypass steps; on second launch double-click works without dialog.
- **Backlog (not in this plan)**: full notarization if/when Apple Developer Program is sponsored. Code path is one new step in release.yml; no architectural changes required.

## v1.1.0 / Task 9: Windows — unsigned + documented SmartScreen bypass (zero-cost, zero-registrations)

**Decision (2026-06-14)**: commercial EV certs cost $200–500/year — **declined**. - **Docs**: `docs/install.md` § Windows — explicit bypass instructions:

## v1.3.0 / Task 29: SSCD neural fingerprint via bundled Meta weights (zero-cost, `[ml-nc]` extra)

**Decision (2026-06-14)**: training a permissively-licensed surrogate would require ~$200 of cloud GPU — **declined**. Instead, ship Meta's published SSCD ResNet50 weights as-is, under their CC-BY-NC license, gated behind an explicit non-commercial `[ml-nc]` optional extra. Users with commercial deployments simply omit the extra and fall back to pHash + chromaprint (unchanged from v1.2). No new code paths, no training pipeline, no money.

- **Files**:
  - `src/yt_uniquifier/core/qa/sscd.py` (CREATE) — ONNX Runtime wrapper around the official SSCD ResNet50 ONNX export. Per-4s chunk inference; cosine distance between source and output embeddings.
  - `src/yt_uniquifier/core/qa/report.py` — new `sscd_divergence_per_chunk: list[float] | None` field on `QAReport` (None when `[ml-nc]` not installed).
  - `src/yt_uniquifier/cli/cmd_qa.py` — `--metric sscd` flag; gracefully fails with "install `[ml-nc]` extra" message when weights absent.
  - `src/yt_uniquifier/core/calibrator.py` — `calibrate --metric sscd` tunes against SSCD distance target (only when extra present).
  - `pyproject.toml` — new `[ml-nc]` extra: `onnxruntime>=1.18`; **no model bundled in wheel**. First-run downloads from Meta's official URL with SHA-256 pin to `~/.cache/yt_uniquifier/models/sscd_imagenet_mixup.onnx`. License banner displayed on first use.
- **Mirror**: existing pHash chunking in `core/qa/` (per-4s windows); marketplace SHA-pin pattern from `profile_marketplace.py`.
- **Test**: `tests/integration/test_sscd.py` (skipif extra missing) — assert non-zero divergence on a transformed clip pair; `tests/unit/test_sscd_extra_missing.py` — `--metric sscd` without the extra fails with a clear, actionable message.
- **License compliance**:
  - `pyproject.toml` extra clearly named `ml-nc` (Non-Commercial).
  - `docs/sscd.md` — explicit "DO NOT USE FOR COMMERCIAL DEPLOYMENTS" banner, link to Meta SSCD license, FAQ on what commercial vs research means.
  - First-run console banner: `"[SSCD] Loaded model under CC-BY-NC. Not for commercial use. See docs/sscd.md."`
  - `[ml-nc]` extra dependency triggers a `RuntimeWarning` if `YT_UNIQ_COMMERCIAL=1` env var is set (operator-declared self-check).
- **Validate**: `pip install -e ".[ml-nc]" && yt-uniq qa output.mp4 input.mp4 --metric sscd` produces a `sscd_divergence_per_chunk` column; without the extra, the same command exits 2 with install hint.
- **Future option (not in this plan)**: train a clean MIT-licensed surrogate on permissive data when funding/GPU sponsorship appears. The Task 29 wrapper code stays; only weights file URL changes.

## Risks

| Risk | Likelihood | Mitigation |
|---|---|---|
| Windows users hit SmartScreen warning on first launch | High (accepted) | Documented bypass in `docs/install.md`; corporate Windows-policy users may be blocked entirely — backlog item to apply to SignPath OSS later if needed |
| AV1 hardware fragmentation across 3 platforms | Mid | Ship libsvtav1 CPU first; add hardware encoders incrementally; per-encoder integration test cell |
| SSCD weights under CC-BY-NC limit commercial adoption | Mid | License clearly gated via `[ml-nc]` extra name + first-run banner + docs; commercial users keep pHash+chromaprint path. No legal exposure for the MIT core. |
| macOS users hit Gatekeeper warning on first launch | High (accepted) | Documented bypass in `docs/install.md`; ad-hoc codesign keeps the bundle stable across OS updates; full notarization remains a backlog item if Apple Developer sponsorship appears |
| Plugin sandbox UX friction (seccomp on Linux only) | Low | Document macOS/Windows fallback; offer `--unsafe-plugins` opt-out for trusted internal plugins |
| Watermark detection false positives | Mid | Tune threshold against a 50-clip false-positive eval set; default `error` is overridable, not `fatal` |
| Competitor (Duplyfi) catches up on resume+VMAF | Mid | v1.2+v1.3 widen the moat (AV1, SSCD, plugin sandbox, signing) faster than they can copy |
