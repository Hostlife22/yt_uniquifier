# yt-uniquifier

> Production-grade re-encoder with controlled micro-transforms for owned/licensed video content.

Intended for legitimate re-upload scenarios — your own content, re-cuts, fair-use
derivatives. **Not** a tool for evading rights-holder detection of third-party content.

Status: **alpha, in development.** See [`specs/README.md`](./specs/README.md) for the
implementation roadmap (Phases 0–5).

## Quickstart (once Phase 0 lands)

```bash
pip install -e ".[dev]"
yt-uniq --help
yt-uniq version
```
